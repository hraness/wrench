Privacy · Wrench {{WRENCH_VERSION}}

This website measures pages, not people.

wrench.rip is a static documentation site. On the canonical production host only, an optional PostHog bootstrap records cookieless, personless, memory-only analytics. The CLI and TypeScript SDK do not send website analytics.

This statement describes the current website analytics contract. It is not a privacy policy for local Wrench state, provider accounts, or captured content.

What the website may record

Allowed events are page view, page leave, Core Web Vitals, and the two explicit GitHub repository links on the home page. The runtime is DNT-aware, query-free, and restricted to the canonical host. URL query strings, fragments, and common attribution parameters are stripped before an event can leave the browser.

The site does not use cookies, replay, identity, feature flags, broad autocapture, console capture, or person profiles. It does not record form input, local file paths, or provider account material. JavaScript is optional; every public page remains readable without it.

Reading without JavaScript

Every public page remains readable without JavaScript. Agents can request Accept: text/markdown on the same URL and receive a Markdown body with Vary: Accept. A Do Not Track signal is honored by the optional analytics bootstrap, so the pages stay useful when that script does not run.

What this page does not cover

Wrench stores local credentials, encrypted snapshots, and archives on the operator's machine. Those artifacts are not website analytics. Use the security guide for local custody, and GitHub private vulnerability reporting on the contact page for suspected product issues.
